從看懂首課，到記錄體會

第一次使用白研社，可以按「看說明—看示範—按指引練習—記錄體會—回看與提問」的順序開始。官網介面預覽幫助你提前認識流程，實際介面以發布版本為準。

App 介面預覽；用於介紹流程，不是可操作的線上體驗。

1. 認識首頁與首課入口

進入 App 後，先查看首頁的首課引導與本人進度，了解目前可以學習的內容。不要把課程預告理解為所有課程均已開放。

2. 讀課程說明與要點

打開「丹田初動·拉風箱」，先理解課程的來源、關注點與目標。遇到不清楚的術語，先結合說明與問答理解，再開始動作練習。

3. 觀察三維動作示範

從不同角度觀察示範，結合文字認識身體各部分的配合。網頁中的固定視角預覽不提供 App 的全部三維控制。

4. 按當次指引開始與結束

使用 App 內的開始入口，遵循當次課程安排。需要結束時使用結束訓練入口；不為追求紀錄自行增加訓練量。具體可用次數與資格以系統實際驗證為準。

5. 留下真實體會

結束後記錄自己的體驗，描述具體位置、變化與不理解之處，不必寫成標準答案。回看本人進度，了解已完成的練習。

6. 圍繞一個具體問題提問

例如：「我理解了腰部後移，但還不清楚它和雙腳的連接，該怎樣理解？」AI 輔助解釋不能代替現場指導或醫療判斷。
